# Zen Blocks Sudoku

Public documentation for the Zen Blocks Sudoku game.

## Documents

- [Privacy Policy](PRIVACY.md) — how the Game handles information (short version: we collect nothing ourselves; Google serves the ads and handles the one purchase)
- [Terms of Use](TERMS.md) — license and terms covering use of the Game

## Data Handling at a Glance

| | |
|---|---|
| Personal data collected by us | None |
| Accounts / sign-in | None |
| Analytics | None |
| Advertising | Google AdMob — a banner, plus an optional video ad you can choose to watch |
| In-app purchases | One: a one-time unlock that removes advertising, processed by Google Play |
| Third-party SDKs | Google Mobile Ads, Google User Messaging Platform, Google Play Billing |
| Data stored on device | Unfinished game, best score, settings, and whether the ad-free unlock was bought |
